= {spec_title} [.spec-status.spec-status-paused]#{spec_status}#

Overview of the openEHR approach to clinical decision support, guideline execution, and workflow coordination. Positions Task Planning, Decision Language, and GDL within the platform and describes their interactions. It explains how decision support, guideline execution, and workflow automation complement each other within openEHR-based clinical systems. Readers planning to implement or integrate any of the PROC specifications should start here to understand the scope and interdependencies.

== Purpose

This document provides an overview of the openEHR PROC component specifications, including the openEHR Decision Logic Module (DLM) Language, {openehr_task_planning}[openEHR Task Planning^] and Subject Proxy service.

The intended audience includes:

* Standards bodies producing health informatics standards;
* Academic groups using openEHR;
* Solution vendors.
