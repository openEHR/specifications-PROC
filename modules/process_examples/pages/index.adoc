= {spec_title} [.spec-status.spec-status-paused]#{spec_status}#

Worked examples of clinical process artefacts illustrating Task Planning, Decision Language, and GDL in real-world care pathway and guideline scenarios, covering common hospital and ambulatory care workflows. Each example includes both the formal artefact definitions and narrative commentary explaining design decisions and implementation considerations.

== Purpose

This document contains elaborated examples of the openEHR Process framework, including Task Plans and Decision Logic Modules, with diagrams in TP-VML.

The intended audience includes:

* Plan and Guideline authors;
* Tool vendors.

== Related Documents

Prerequisite documents for reading this document include:

* The {openehr_task_planning}[openEHR Task Planning Model^];
* The {openehr_decision_language}[openEHR Decision Language^];
* The {openehr_tp_vml}[openEHR Task Planning Visual Modelling Language (TP-VML)^];
