= {spec_title} [.spec-status.spec-status-paused]#{spec_status}#

Visual Modelling Language for Task Planning: a graphical notation for designing, communicating, and validating clinical care plans and workflow structures using standardised diagram elements. The notation covers task boxes, decision diamonds, event triggers, performer swimlanes, and timing constructs, providing a complete visual vocabulary for care plan design. TP-VML diagrams can be used both as implementation blueprints and as communication tools for clinical teams and system architects.

== Purpose

This document describes a visual modelling language for the openEHR Task Planning Model, known as TP-VML. This is designed to enable visually efficient visual representations of Task Plans to be authored with appropriately configured tools.

The intended audience includes:

* Task Plan and workflow authors;
* Tool vendors.
